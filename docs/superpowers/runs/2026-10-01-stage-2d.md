## In plain English

You played FilePlus again on 2026-10-01 and wrote down everything that felt wrong. This run went
through that list, and through 62 smaller problems an earlier audit had found, and fixed them. It
also went looking for "cousins" of each problem — the same kind of mistake somewhere else in the app —
and fixed those too.

What you should notice:

- **Views work like Explorer's.** Ctrl + mouse wheel now walks Explorer's eight views in order:
  Content, Tiles, Details, List, Small icons, then icons that grow smoothly from Medium to Extra large.
  List is the real multi-column list that scrolls sideways. Names in big icon views wrap onto up to
  four lines instead of being cut off at the bottom, and icons stay square. Every folder remembers its
  own view, even after a restart.
- **No more icon flashing.** Switching folders or tabs no longer shows the FilePlus icons first and
  then swaps in the Windows ones. Icons that were already seen appear instantly; new ones fade in once,
  in place. Pictures show as real thumbnails in any folder, in their own shape.
- **Zoom (Ctrl + plus / minus) no longer squeezes the side panels.** The sidebar and the inspector keep
  their width on screen; only their text gets bigger. Each zoom step glides instead of jumping.
- **Refresh (Ctrl+R, F5 or the button) refreshes in place.** It keeps your scroll position and your
  selection and only changes the rows that changed. It can no longer reload the whole app.
- **This PC is a real page** with a card per drive: icon, name, a usage bar (red when nearly full) and
  "X GB free of Y GB". Opening "This PC" no longer drops you into the sandbox folder.
- **The toolbar behaves.** The new-tab button is a plain "+". The folder path starts on the left; when
  space runs out the search box shrinks, then folds into a magnifier button, and only then does the
  path give way. Ctrl+F opens search.
- **Sort has a "Date…" sub-menu** with Date created, Date modified and Date accessed. Menus can now have
  sub-menus.
- **The sidebar is tidier:** bigger section headings, thin divider lines, tighter spacing, bigger icons
  when collapsed, and a thin scrollbar that only shows when you need it. It never scrolls sideways.
- **Nothing on screen pretends to work.** Buttons and pages for features that are not built yet (AI,
  scanning, the review bin and so on) are hidden until their stage, instead of doing nothing when
  clicked. The Settings › About, Shortcuts and Data pages now show real information and real actions.
- **Smaller things:** cut files look faded and copied files get a small dot; the maximise button turns
  into "restore" when the window is maximised; error messages no longer pile up on top of each other
  and go away after 8 seconds; the inspector never shows a file that is not selected; deleting a file
  selects the next one, like Explorer; Back and Forward return you to where you were in each folder.

What is hidden until a later stage is listed under [Hidden until later stages](#hidden-until-later-stages).
What is still not right is under [Known open items](#known-open-items). The things worth trying
yourself are at the end, under [Feel check](#feel-check-for-jj).

## Known open items

- **`ERR_CONNECTION_FAILED` on `/recent`** — seen once in a full test run (Task 12a). The request never
  reached the backend; four later full runs did not reproduce it. Root cause unknown.
- **Dropping a file from Windows Explorer onto FilePlus is blocked, not copied in.** Explorer would copy
  it; FilePlus refuses because nothing may write without an explicit approved action. A real "copy in"
  needs its own design.
- **Middle-click on a folder does not open it in a new tab** (not built). Middle-click on a tab closes it.
- **`frontend/tray/` and `frontend/setup/` are not swept.** They are not loaded by the main window and the
  menu gate does not scan them; their dead controls are debt for the stage that ships the tray and setup.
- **The file list keeps Chromium's own scrollbar** (spec §9.3 ruling: a long folder needs a precise drag).
- **Deferred minors still open** (from the review ledger):
  - a system clock that jumps backwards can lose one folder-view choice (`t = max(now, stored.t + 1)` would fix it);
  - in the repeated hour at a daylight-saving change, a file's mtime can look changed on every inspector
    open and be re-hashed each time;
  - a `null` entry in `ui.folder_views` would crash the 500-entry prune (validate entry shape server-side);
  - `POST /config/merge` into a key that holds a non-object replaces it with `{}`;
  - the window-close flush can send its keepalive twice (`pagehide` + `beforeunload`; harmless, deltas commute);
  - a delete-refresh test comment claims a little more than the test checks;
  - `formatModified` is a thin alias of `formatDate`; `refreshFxMs` reads the refresh tokens once;
    `failNavigation`'s non-browser-screen branch is nearly unreachable.
- At 150 % zoom on an 800 px window with the inspector open the path shows less than one folder name
  (it ellipsizes, never fades) — expected for that little room.

## Feel check (for JJ)

Try these on your real folders (start the app the usual way):

1. **Views:** open a folder with many files, hold Ctrl and roll the mouse wheel slowly up and down. It
   should step through Content, Tiles, Details, List, Small icons, then icons growing to huge, one step
   per notch, with nothing jumping or flashing. Leave one folder in Large icons, restart the app, and
   open that folder again — it should still be Large icons.
2. **No flash:** switch back and forth between two tabs, and between two folders you already visited,
   with Windows icons on (Settings › Personalization › File icons). The icons should simply be there.
3. **Zoom:** press Ctrl and + three times, then Ctrl and 0. The sidebar and the inspector should keep
   their width while everything in them gets bigger, and each step should glide.
4. **Refresh:** scroll halfway down a long folder, select a file, then press F5 (and Ctrl+R). Nothing
   should jump; your scroll and selection stay. Add a file to that folder from Windows Explorer and
   refresh again — it should just appear.
5. **This PC:** click "This PC" in the sidebar. You should see a card per drive with a usage bar and
   "free of" text. Double-click a drive, then press Alt+Up to come back.
6. **Toolbar squeeze:** make the window narrow and go deep into folders. The search box should shrink,
   then turn into a magnifier, and only then should the path start hiding its beginning. Press Ctrl+F.
7. **Sort by date:** click the Sort button and hover "Date…"; pick "Date created".
8. **Cut and paste:** select two files and press Ctrl+X — they should look faded. Go to another folder
   and press Ctrl+V; the moved files should be selected there.
