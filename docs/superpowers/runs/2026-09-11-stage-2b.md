## Known debts (not fixed in 2B)

- `saveSetting` calls are fire-and-forget; rapid same-key changes can revert `__fpConfig` to a stale
  value on a transient failure.
- Toggle-hidden request ordering (T4 deferred): `cm-toggle-hidden` now routes through `saveSetting()`
  (Task 8b carry-over), so a rapid double-toggle hits exactly the fire-and-forget ordering debt above —
  this is the same debt, not a separate one, now that the bespoke revert-on-failure code it used to have
  is gone.
- `pins_add` undo-of-remove recreates the pin with a default label (original label not logged).
- Concurrent `undo_operation` calls on the same op id can both act (same race class as pre-existing
  file-op undo; inverses are idempotent).
- `path_guard` runs synchronously inside async routes; a genuinely remote UNC target still blocks the
  loop for the SMB timeout (loopback case fixed in 8a).
- `OSError` -> 502 handler special-cases only `EINVAL` for 400.
- Defence-in-depth re-map after `resolve()` adds one bounded (≤2 s) host lookup for genuine remote UNC
  writes.
- Tab context menu: duplicate tab, close other tabs, pin tab, and rename tab have no underlying
  tab-state implementation (new in this task's findings, not a Stage 2B regression — the Tab menu was
  documented as "purely client-side state, no backend" and that client-side state was never built).
  `scripts/check_menu_cases.js` allowlists these four by name so a *real* regression (a menu item losing
  its case) still fails the gate.
- Inspector Preview tab handles text/binary/too-large only; image/pdf/audio/video/archive preview
  kinds from the original design doc are not built.
- Recent-row thumbnails (`GET /thumb`), tag-canvas-driven tag chip context menu, and Everything Folder
  error badge are unbuilt (later-stage screens).

## How to review

Switch to the branch; run verify; then `npm start` from `frontend/` against a `py -3 -m backend.api`
backend (or let `verify.ps1` do both) and walk the graduation steps from spec §10 inside the sandbox:

1. Use FilePlus for a while against `FilePlusTestSandbox` with `WRITE_UNLOCKED=false` (the shipped
   default) — browse, rename, tag, favorite, pin, undo/redo, trigger a conflict, empty the trash pane.
2. When comfortable, set `WRITE_UNLOCKED=true` in `.env` at your own pace.
3. Only then point the sidebar/pins at real folders outside the sandbox.

Merge in two commands:

```bash
git checkout master
git merge --no-ff stage/2b-frontend
```
