Welcome to FilePlus

An AI-driven file manager for Windows. It watches your filesystem, classifies files with local AI, and proposes organised structures. You approve every move before it happens.

Nothing runs without approval — every file operation is shown first
Local-first — AI runs on your machine with Ollama, no data leaves unless you add an API key
Sandbox mode active during setup — changes only inside the designated test folder
